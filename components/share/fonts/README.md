# Share-card fonts

`InterVariable-opsz.woff` is Inter 4.001 (Google Fonts build, `Inter-VariableFont_opsz,wght`),
subset to Latin with every layout feature and both variation axes kept. It is the
exact build the approved Chain Revenue v17 mockup was rendered with.
